## Multi-Repository Orchestration

To clone and synchronize all repositories across the organization locally, run the included  utility:

```bash
# Clone the complete ecosystem into the current workspace
bash clone-all-repos.sh
```

### Environment Synchronization Options

| Flag / Option | Description | Target Environment |
| :--- | :--- | :--- |
| `--protocol ssh` | Use SSH (`git@github.com:...`) for authenticated operations. | Standard development machines. |
| `--protocol https` | Use HTTPS (`https://github.com/...`) for read-only CI or token access. | Containerized pipelines. |
| `--shallow` | Perform shallow clones (`--depth 1`) to minimize disk usage and transfer time. | Ephemeral runner test harnesses. |

## Documentation Standards

All repositories in the ecosystem adhere to the following unified standards:
- **English-Only Authoring**: All documentation is authored exclusively in English under `docs/en/`.
- **Pre-Release Clean-Break**: Direct representation of current API contracts without migration baggage or backward-compatibility shims.
- **Strict RFC Identifiers**: Documentation placeholders strictly use RFC 5737 IPv4 addresses (`192.0.2.0/24`, `198.51.100.0/24`, `203.0.113.0/24`) and RFC 2606 domain names (`example.com`, `example.net`, `example.org`).
